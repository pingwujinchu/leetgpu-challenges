🚀 题目运行环境

🏗️
主从架构 (Master-Worker)

主网站运行在CPU机器上负责任务分发和控制，从节点运行在GPU机器上接收任务并根据资源情况执行

🔄 系统架构

🖥️
主节点 (Master)

CPU机器 - 任务分发与控制

→
🎮
从节点 (Worker)

GPU机器 - 接收任务并执行

📤

主节点职责: 接收题目提交请求，使用Ray将任务分发到合适的GPU从节点

📥

从节点职责: 接收任务后判断本地GPU资源（显存、计算能力），确定是否可以运行并执行

📦 Docker 镜像

基础镜像:

micr.cloud.mioffice.cn/cloudml-preset/cuda:12.8.1-py3.12-ubuntu22.04-0.1
🐍 Python 3.12 🎮 CUDA 12.8.1 🐧 Ubuntu 22.04

从节点使用此Docker镜像运行题目代码，支持CUDA加速计算

🎮 GPU 节点选择

您可以选择具体的GPU型号，主节点会将任务分发到对应型号的从节点。从节点会根据当前资源情况（显存占用、GPU利用率等）判断是否执行任务。

💡 选择特定GPU型号后，主节点会分发到对应从节点。从节点会检查资源后决定是否运行，资源不足时会返回错误或等待。

⚡
Ray 分布式调度

使用Ray框架实现主从节点通信、任务分发和资源管理，支持智能负载均衡和故障恢复。
